অ্যাডমিন কী নেই

কী নামানোর নিয়ম (একবারই লাগবে):
  1. Firebase Console ওপেন করো → তোমার প্রজেক্ট (our-habit-61587)
  2. ⚙️ Project Settings → Service accounts ট্যাব
  3. নিচের নীল বাটন “Generate new private key” চাপো
  4. ডাউনলোড হওয়া JSON ফাইলটাকে নাম বদলে admin-sdk-key.json করে প্রজেক্ট ফোল্ডারে রাখো (package.json যেখানে আছে ঠিক সেখানে)
  5. তারপর bun run dev দিয়ে সার্ভার চালু করো আর এই প্যানেল রিফ্রেশ দাও

⚠️ admin-sdk-key.json কারো সাথে শেয়ার করবে না — এটা তোমার পুরো Firebase প্রজেক্টের মাস্টার চাবি।

সার্ভার কানেক্ট হচ্ছে না

এই প্যানেল (GitHub Pages) শুধু একটা রিমোট। আসল ডেটা আসে তোমার পিসির সার্ভার থেকে — কারণ Firebase-এর মাস্টার কী (admin-sdk-key.json) কখনোই কোনো পাবলিক ওয়েবসাইটে রাখা যায় না। তাই প্যানেল খোলার আগে পিসিতে অ্যাপের সার্ভারটা চালু থাকতে হবে:

  1. পিসিতে প্রজেক্ট ফোল্ডার ওপেন করো → টার্মিনালে bun run dev লিখে এন্টার (লেখা দেখাবে: localhost:3000)
  2. নিচের ঠিকানাটা ঠিক আছে কিনা দেখো
  3. তারপর আবার চেষ্টা করো

🌐 সার্ভার

এই প্যানেলটা GitHub Pages-এ থাকে, কিন্তু ডেটা আসে তোমার পিসির সার্ভার থেকে (default: http://localhost:3000)। কারণ সার্ভারে Firebase-এর মাস্টার কী আছে — সেটা কখনো পাবলিক ওয়েবসাইটে রাখা যায় না। পিসিতে bun run dev চালু থাকলেই প্যানেল কাজ করবে।

ঠিকানা

ℹ️ কীভাবে কাজ করে

  1. এই ফাইলটা (index.html) GitHub রিপোতে থাকে → GitHub Pages সেটা চালায়।
  2. পিন দিলে সেটা যায় তোমার পিসির সার্ভারে (/api/admin/session) — সার্ভার হ্যাশ করে মিলিয়ে দেখে, তারপর টোকেন দেয়।
  3. সেই টোকেন দিয়েই প্যানেল ইউজার লিস্ট, স্ট্যাটাস, ব্যান/আনব্যান, পাসওয়ার্ড, অ্যাডস — সব কমান্ড চালায়।
  4. পিন কখনো পেজের কোডে লেখা থাকে না — তাই পেজ পাবলিক হলেও তোমার পিন তোমার কাছেই থাকে।
